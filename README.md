# 🚀 Хакатон: Автономный мультиагентный оркестратор инфраструктурных задач

Этот репозиторий содержит полный конвейер для автономного решения 100+ задач с жесткими ограничениями по времени (1 час), бюджету токенов (80k–100k output-эквивалентов) и наличием «ловушек» (невыполнимых задач).

Архитектура состоит из трех ключевых компонентов:
1. **Препроцессор** — локальный математический анализатор и решатель задачи о рюкзаке (Knapsack + LPT Scheduler).
2. **Оркестратор (`orchestrator.py`)** — асинхронный мультиагентный диспетчер, управляющий агентами через семафоры и исполняющий расписание.
3. **Индексатор (`indexer.py`)** — сканер результатов, который проверяет наличие и валидность файлов `answer.txt` перед финальной сдачей.

---

## 🏗 Архитектура системы

```text
  task-dir/ ──► [ 1. Препроцессор ] ──► kpi_result.json ──► [ 2. Оркестратор ] ──► answer.txt ──► [ 3. Индексатор ]
                    (Локальный КПИ)                        (Async 5 Agents)                     (Валидация)
```

---

## 1. ⚙️ Препроцессор задач (Pre-processing Engine)
Модуль локального анализа (без затрат токенов LLM), который выполняет следующие функции за считанные секунды:
* **Сбор и валидация**: парсит `task.json`, исследует файлы в `workspace/` и каталоге `kb/`.
* **Детекция ловушек (`fs_claims`)**: сверяет утверждения из инструкций с реальным состоянием диска (существование файлов, количество строк, наличие колонок). Задачи с критическими расхождениями получают статус `unlikely` и исключаются из бюджета.
* **Оптимизация рюкзака (Knapsack DP)**: максимизирует суммарную ценность задач (`reward × p_solved`) при соблюдении лимита бюджета в **80 000 output-эквивалентов токенов**.
* **Планировщик (LPT Scheduler)**: распределяет отобранные задачи по **5 параллельным агентам**, гарантируя укладывание в лимит 3600 секунд.

### Запуск препроцессора:
```bash
python main.py ./task-dir config.yaml
```
**Выход:** `task-dir/kpi_result.json` (машиночитаемый контракт для оркестратора) и `task-dir/kpi.csv` (таблица для анализа).

## 2. 🤖 Оркестратор задач (`orchestrator.py`)
Оркестратор читает `kpi_result.json`, берет готовый план из `knapsack.selected` и `schedule_hint.per_agent_plan`, после чего запускает асинхронный пул агентов.

### Ключевые особенности оркестратора:
* **Асинхронность и лимиты**: использует `asyncio.Semaphore(3)` для соблюдения ограничений пропускной способности API.
* **Защита от обрезания контекста (Front-loaded Tags)**: модель обязана возвращать результат в самом начале ответа, оборачивая его в маркеры `*****answer*****`. Если ответ упирается в лимит `max_tokens`, критически важная часть на старте гарантированно сохраняется.
* **Адаптивный пост-процессинг**: 
  * Для задач `coding_*` парсер автоматически вычленяет чистый блок кода внутри ````python ... ````.
  * Для `math_*`, `search_*` и `data_analysis_*` извлекаются точные скаляры (числа, города, имена).
* **Изоляция директорий**: каждая задача выполняется в изолированной подпапке `task-dir/<task_id>/`, результаты записываются строго в `answer.txt`.

### Запуск оркестратора:
```bash
uv run orchestrator.py
```

---

## 3. 🔍 Индексатор результатов (`indexer.py`)
Инспектор выходных артефактов, который запускается после завершения работы всех агентов для верификации и построения итогового отчета.

### Что делает индексатор:
1. Сканирует директорию `task-dir/` в поисках всех файлов `answer.txt`.
2. Подсчитывает общее количество успешно решенных задач.
3. Проверяет содержимое файлов на предмет пустоты или лишнего текстового мусора («воды», рассуждений).
4. Выводит сводную статистику по затратам токенов и среднему потреблению на одну задачу.

### Запуск индексатора:
```bash
uv run indexer.py
```

---

## 📋 Формат контракта (`kpi_result.json`)
Оркестратор опирается на следующие ключевые поля из сгенерированного препроцессором файла:
* `knapsack.selected` — список `task_id`, одобренных к решению.
* `schedule_hint.per_agent_plan` — распределение задач по агентам (от 1 до 5).
* `tasks[i].recommended_model` — выбор модели (`qwen3.8-27b` для сложных или `qwen3.6-35b-a3b-noreason` для остальных).
* `tasks[i].cost_reason_safe` — зарезервированный бюджет токенов.
